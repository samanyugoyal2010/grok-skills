# grok-skills

Public directory and CLI for **Grok Bot** skills — a skills.sh-style leaderboard and one-command installer, aimed at Grok Bot (and Grok Build’s `.grok/skills` paths).

This repository currently holds the product plan only. Implementation has not started.

See **[PLAN.md](./PLAN.md)** for:

- How skills.sh works (directory + CLI + install telemetry)
- How Grok Bot skills, plugins, and routines actually work
- Proposed site, CLI, schema, security, and delivery phases
