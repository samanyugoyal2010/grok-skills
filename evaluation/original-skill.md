# HTTP endpoint implementation

## Description

Use this skill when adding an HTTP endpoint to a TypeScript server.

## Procedure

1. Understand the endpoint request and response shape.
2. Add the route to the server.
3. Add an integration test for the successful response.
4. Run the test suite and report the result.

## Constraints

Keep the change small and avoid breaking existing routes.

## Examples

Add a health endpoint and return a successful JSON response.
